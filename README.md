

📝 To-Do List Application

📌 Overview

The To-Do List Application is a simple command-line project developed using Python. It helps users manage their daily tasks through an interactive menu-driven interface. Users can add new tasks, view existing tasks, remove completed tasks, and exit the application whenever they want.

This project was built as part of my Python learning journey to strengthen my understanding of fundamental programming concepts such as lists, loops, conditional statements, user input handling, and program logic.


---

🚀 Features

Add new tasks to the list

View all current tasks

Remove tasks by selecting their task number

Display a message when no tasks are available

Validate user input for task removal

Menu-driven interface for easy navigation

Exit the application safely

📋 How the Application Works

Main Menu

===== TO-DO LIST =====

1. Add Task
2. Remove Task
3. Display Tasks
4. Exit

Add Task

Users can enter a new task, which is stored in the task list.

Display Tasks

All current tasks are displayed with numbering for easy identification.

Remove Task

Users can remove a task by entering its corresponding task number.

Exit

The application terminates when the user chooses the Exit option.
